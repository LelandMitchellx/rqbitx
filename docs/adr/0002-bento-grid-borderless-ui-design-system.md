# 0002. 便当盒（Bento Grid）无边框 UI 设计系统

- **状态**: 已接受 (accepted)
- **日期**: 2026-10-15

## 背景

`rqbitx` 的演示示例（Example）、开发者测试台以及未来的前端客户端模块，需要一套统一且现代的视觉语言。如果没有明确的设计规范，不同开发者或后续 AI 辅助编码时容易引入杂乱无章的样式风格（例如生硬的卡片黑边线描、过时的 Material 2 质感卡片、间距不一致，或者引入沉重的第三方 UI 样式组件库）。

## 决策

### 界面拓扑演进（AppBar + 高度聚合 Bento 模块）
1. **顶部导航回归 Native AppBar**：
   - 将先前浮动在滑动列表内的标题 Bento 卡片抽离为原生的 `Scaffold.appBar`，消除多余嵌套。
   - 包含品牌 Logo、副标题以及常驻右上角的主题切换控制器（`_themeToggle`），背景与 Scaffold 无缝融合（`elevation: 0`，零阴影）。
2. **“服务管理”超高内聚统一 Bento 卡片**：
   - 坚决避免信息碎片化：将原先分散在不同卡片的“启动/断开服务”、“运行状态与监听端口”、“服务根 URL 显示”、“一键复制服务地址”、“HTTP GET 探测”完整收纳聚合至同一个「服务管理」Bento Box 中。
   - 内部按色阶规范划分子区块，呈现清晰紧凑的仪表盘质感。

我们为 `rqbitx` 的示例工程与前端交互界面确立了**便当盒（Bento Grid）无边框设计系统**作为官方标准：

1. **便当盒模块化网格（Modular Bento Tiles）**：
   界面由自包含的矩形卡片模块组成，按清晰的功能层级组织在网格流中（包括：页眉状态、生命周期控制、实时指标统计、HTTP 地址终结点、控制台响应日志）。
2. **纯粹无边框与扁平色彩层次（Borderless & Pure Flat Hierarchy）**：
   - 严禁使用生硬的边框线条（避免使用 `Border.all` 实体描边）。
   - 严禁使用背景阴影（零 `boxShadow`、零 `elevation`），保持极简扁平的高级现代感。
   - 纯粹通过画布与卡片的色彩对比建立空间层级（画布背景采用浅冷灰底色 `#F1F3F7`，卡片采用纯白底色 `#FFFFFF`）。
3. **大圆角现代几何几何学（Curved Geometry）**：
   主功能瓦片统一采用宽裕的圆角弧度（`BorderRadius.circular(22)`），内部控件与徽章采用 `12~14` 圆角。
4. **轻量纯粹、零额外依赖（对齐 Ponytail 极简理念）**：
   - 仅使用 Flutter 官方基础核心组件（`Container`, `Column`, `Row`, `ElevatedButton`）构建。
   - 严禁引入 Tailwind 类封装库或庞大的第三方组件库。

## 结果与影响

- **收益（正面）**：
  - 界面风格统一且极具现代感，后续 AI 或团队成员在编写新 UI 时有法可依，消除设计发散。
  - 纯原生组件渲染，包体积无额外负担，流畅度极佳。
- **代价（负面）**：
  - 在平板或大屏自适应响应式布局下，需要手动处理 Bento 卡片的流式排版或跨列比例。
